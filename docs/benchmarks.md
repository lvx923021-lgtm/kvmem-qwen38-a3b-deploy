## 4. 复现说明

- 44 题基准需要自建题集与判分逻辑（本仓库不附带题目文本，避免评测集污染）。
- 测速时建议：先发一次 warmup，再连续发同一提示两次，取第二次的 `timings`（缓存/前缀复用会显著改变结果）。
- 长文召回：文档中段埋唯一验证码（如 `KV-MEM-256K-TEST`），确认回答逐字符正确。
- 所有数字为**单机单卡**实测，硬件/驱动/量化/后台负载都会影响结果。
